# Compare the users or launches actually exposed

1. Name the decision and the population eligible for the update. Distinguish assignment, download, installation and confirmed execution. Use the unit that can actually experience the outcome.
2. Align platform, exposure age, observation window and reporting lag for the candidate and baseline. Define the numerator and denominator on the same unit. Keep unknown or incomplete exposure visible.
3. Calculate counts and rates for comparable cohorts. Check sample size, repeated events, selection differences and missing reports. State what the comparison can support under the team's existing rollout criteria.
4. Report a bounded recommendation and the next observation that would change it. If a cohort has no mature exposure yet, defer that comparison instead of converting missing outcomes into zero failures.
